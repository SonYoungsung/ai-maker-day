친구 파티 궁합 분석기

친구들끼리 서로의 궁합을 보며 웃고 이야기하게 만든다

핵심 경험

두 친구의 특징을 넣으면 캐릭터 카드와 궁합 점수·한줄평이 나온다.

메인 흐름 (Main Flow)

  1. 홈에서 시작 버튼을 누른다
  2. 친구 A의 이름과 특징 3개를 입력한다
  3. 친구 B도 똑같이 입력한다
  4. 분석하기를 누른다
  5. 캐릭터 카드 2장과 궁합 점수·한줄평을 확인한다

화면 설계 (Screens)

1. Home — 프로젝트 소개와 시작 · 제목/설명/시작 버튼 · 시작 → 입력
2. Input — 친구 2명 정보 입력 · 이름칸/특징 태그 3개/분석 버튼 · 분석 → 결과
3. Result — 카드와 궁합 보여주기 · 카드 2장/점수 게이지/한줄평/다시하기 · 다시하기 → 입력

기능 우선순위

Must

  • 친구 2명 입력
  • 캐릭터 카드
  • 궁합 점수
  • 한줄평

Nice

  • 카드 이미지 저장

Later

  • 그룹 궁합
  • 공유 링크

AI가 하는 일

하는 일: 입력한 특징으로 캐릭터 설명과 궁합 한줄평 생성

입력: 이름 + 특징 3개 × 2명

반환: 캐릭터 한줄 설명, 궁합 점수(0-100), 재미있는 한줄평

개발 순서 (Build Order)

  1. 3개 화면 뼈대 만들기
  2. 입력 폼 만들기
  3. 궁합 점수 계산 로직
  4. AI 한줄평 연결
  5. 결과 카드 디자인
  6. 테스트

오늘의 완료 기준 (Definition of Done)

  • 3개 화면이 이어진다
  • 친구 2명 입력 → 결과까지 한 번에 된다
  • 점수와 한줄평이 나온다

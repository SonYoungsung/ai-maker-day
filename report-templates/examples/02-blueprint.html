친구 파티 궁합 분석기

친구들끼리 모였을 때 5초 만에 웃을 거리를 만든다

누가 쓰고, 무엇을 얻어 가나

Target User
우리 반 친구들
Core Experience
친구 2명의 이름과 특징을 넣으면 캐릭터 카드 2장과 궁합 점수·한줄평이 나온다.

사용 흐름 (Main Flow)

  1. 열면 친구 2명 입력칸이 바로 보인다.
  2. 이름을 적고 특징을 3개씩 고른다.
  3. 궁합 보기 버튼을 누른다.
  4. 아래에 캐릭터 카드 2장 + 궁합 점수 + 한줄평이 나타난다.

화면 — 메인 한 장이면 충분

Purpose
입력부터 결과까지 한 화면에서 끝낸다
Main Content
큰 제목과 친구 2명 입력 카드
Primary Action
궁합 보기 버튼 — 보라색, 화면에서 가장 큼
Secondary
다시 하기 버튼
Result
버튼 아래에 캐릭터 카드 2장, 궁합 점수, 한줄평이 나타난다

화면 요소 (UI Elements)

Button
궁합 보기(보라, 큼) / 다시 하기(테두리만)
Input
이름 입력칸 2개 — 안내 문구 "친구 이름을 적어줘"
Card
캐릭터 카드 2장을 나란히, 그 아래 점수와 한줄평
Result
점수는 큰 숫자, 한줄평은 한 문장

비주얼 방향

Mood
밝고 귀여운 파스텔, 카드 게임 느낌
Colors
보라(#6c5ce7) 강조 + 연보라 배경 · 강조색은 하나만
Typography
제목은 둥글고 굵게, 점수는 아주 크게
Shape
모서리 많이 둥글게
Animation
결과가 아래에서 살짝 떠오르기

휴대폰에서 볼 때

  • 입력 카드 2개를 세로로 배치
  • 버튼은 화면 가로를 꽉 채우기
  • 점수 글자는 더 크게

기능 범위

친구 2명 이름 입력 특징 3개씩 고르기 궁합 점수 계산 캐릭터 카드 2장 + 한줄평

Nice to Have

  • 다시 하기 버튼
  • 결과 링크 복사

Later

  • 3명 이상 그룹 궁합
  • 결과 이미지로 저장
AI는 쓰지 않기로 했어요. 겹치는 특징 개수로 점수를 계산하고, 한줄평은 점수 구간별로 미리 써둔 문장에서 고르면 충분합니다. 억지로 AI를 넣지 않았습니다.

만드는 순서 (Build Order)

  1. 기본 화면과 제목 만들기
  2. 친구 2명 입력칸과 특징 고르기 만들기
  3. 궁합 보기를 누르면 점수가 계산되게 하기
  4. 캐릭터 카드와 점수·한줄평 보여주기
  5. 처음부터 끝까지 한 번 실행해보기

오늘 여기까지 되면 성공

  • 메인 화면이 보인다
  • 친구 2명을 입력할 수 있다
  • 궁합 점수가 나온다
  • 처음부터 끝까지 한 번 실행된다

친구 파티 궁합 분석기

이름과 특징을 넣으면 캐릭터 카드와 궁합 점수가 진짜로 나온다

실행 방법 — 바탕화면 AI메이커데이 폴더의 내프로젝트.html 을 더블클릭하면 브라우저에서 바로 열립니다. 설치할 것도, 켜 둘 것도 없습니다.

이번에 만든 것 (Done)

  • 메인 화면과 제목 만들기
  • 친구 2명 이름 입력칸 만들기
  • 특징 칩 3개씩 고르는 기능
  • 겹치는 특징으로 궁합 점수 계산하기
  • 캐릭터 카드 2장 + 점수 + 한줄평 보여주기

지금 되는 것 (How It Works)

친구 2명의 이름을 적고 특징을 3개씩 고른 뒤 궁합 보기를 누르면 → 겹치는 특징 개수로 0~100점을 계산하고 → 점수 구간에 맞는 한줄평을 골라 보여준다.

🐞 막혔던 것

문제
궁합 보기 버튼을 눌러도 아무 일도 일어나지 않았다.
원인
버튼은 만들어졌는데, 눌렀을 때 실행될 기능이 연결되지 않았다. 함수 이름을 다르게 적었던 것.
해결
버튼에 적힌 이름과 실제 기능 이름을 똑같이 맞췄다.
배운 것 — 버튼이 안 먹히면 버튼 모양이 아니라 "눌렀을 때 실행될 것"이 연결됐는지부터 본다.

직접 확인한 것 (Test)

  • 화면이 보인다
  • 이름을 입력할 수 있다
  • 특징을 고를 수 있다
  • 궁합 점수가 나온다
  • 한줄평이 나온다

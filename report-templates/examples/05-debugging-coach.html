친구 파티 궁합 분석기

분석 버튼이 안 먹던 문제를 스스로 찾아 해결했어요

1

Problem — 무슨 문제였나

분석하기 버튼을 눌러도 결과 화면으로 넘어가지 않고 아무 반응이 없었다.

2

Cause — 원인

버튼에 연결한 함수 이름과 실제 함수 이름의 철자가 달랐다. analyze() 로 만들어놓고 버튼에는 analze() 라고 오타로 연결해서, 콘솔에 "함수가 없다"는 오류가 났다.

3

Fix — 무엇을 고쳤나

함수 이름을 analyze 로 통일하고 버튼에 정확히 다시 연결했다.

4

Test — 다시 확인

친구 2명을 입력하고 분석하기를 누르니 결과 카드가 정상적으로 나타났다.

★

Learned — 배운 것

"안 돼요"가 아니라 "버튼을 눌러도 콘솔에 함수가 없다는 오류가 난다"처럼 구체적으로 말하면 원인을 훨씬 빨리 찾을 수 있다.

친구 파티 궁합 분석기

친구 2명의 이름과 특징을 넣으면 궁합 점수와 한줄평이 나온다

실행 방법 — 바탕화면 AI메이커데이 폴더의 내프로젝트.html 을 더블클릭하면 브라우저에서 바로 열립니다.

왜 이걸 골랐나

"친구들이랑 모이면 할 게 없어서 폰만 보는데, 같이 웃을 거리가 있으면 좋겠어서."

지금 되는 것

친구 2명 이름을 적고 특징을 3개씩 고른 뒤 궁합 보기를 누르면 → 점수와 한줄평이 나온다.

AI가 정한 것

처음 만들 때 AI가 알아서 정해놓은 것들 — 마음에 안 들면 다음 단계에서 바꾸면 된다.

  • 이름은 "궁합 메이커"로 정함
  • 화면은 한 장 — 입력칸 2개와 버튼 하나, 결과는 아래에 카드로
  • 색은 보라 계열 파스텔
  • 점수는 겹치는 특징 개수로 계산 (AI 없이 규칙으로)
  • 한줄평은 점수 구간별로 미리 써둔 문장에서 고름
  • 캐릭터 그림은 일단 뺌

내가 바꾼 것

  • 이름을 "궁합 메이커" → "친구 파티 궁합 분석기" 로 바꿈
  • 한줄평이 너무 밋밋해서 더 웃긴 문장으로 교체

🐞 막혔던 것

문제
궁합 보기 버튼을 눌러도 아무 일도 안 일어났다.
원인
버튼은 있는데 눌렀을 때 실행될 기능이 연결되지 않았다.
해결
버튼과 기능 이름을 똑같이 맞췄다.
배운 것 — 버튼이 안 먹히면 버튼 모양이 아니라 "눌렀을 때 실행될 것"이 연결됐는지부터 본다.

다음에 바꾸고 싶은 것

  • 결과를 링크로 복사해서 친구한테 보내기
  • 배경이 너무 허전함

우리 반 케미 요정

친구 파티 궁합 분석기 — 3분 발표문

3분 발표문

1. Problem

반에서 자리를 새로 바꿀 때마다 누구랑 앉을지, 누구랑 잘 맞을지 늘 고민이었어요.

2. Idea

그래서 친구 두 명의 특징을 넣으면 궁합 점수를 매겨주는 '친구 파티 궁합 분석기'를 만들었어요.

3. Build

이름과 특징 3개를 넣으면 캐릭터 카드 2장과 궁합 점수, 재미있는 한줄평이 나와요.

4. Challenge

분석 버튼을 눌러도 결과가 안 나오는 문제가 가장 어려웠는데, 함수 이름 철자가 틀린 걸 찾아서 고쳤어요.

5. AI

AI에게는 한줄평 문장과 점수 계산 아이디어를 도움받았고, 어떤 특징을 쓸지와 디자인 색은 제가 직접 정했어요.

6. Result

친구 두 명만 넣으면 3초 만에 궁합 카드가 나오는 웹앱을 완성했어요.

🎬 시연 순서 (Demo Order)

  1. 프로젝트 한 줄 소개
  2. 홈 화면 보여주기
  3. 친구 2명 입력 시연
  4. 분석 결과 카드 보여주기
  5. AI를 어떻게 썼는지 설명
  6. 가장 재미있었던 부분 이야기

✅ Demo Checklist

  • 프로젝트가 실행됨
  • 핵심 기능 작동
  • 보여줄 친구 예시 미리 정함
  • AI 사용 설명 준비
  • 어려웠던 점 설명 준비
  • 마지막에 결과 카드 보여주기

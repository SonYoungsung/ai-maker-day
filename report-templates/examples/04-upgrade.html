친구 파티 궁합 분석기

"작동한다"에서 "내가 만든 것 같다"로

추가한 기능 (Added)

결과 링크 복사

결과가 나온 뒤 링크 복사를 누르면 궁합 결과가 담긴 주소가 복사돼서, 친구한테 바로 보낼 수 있다.

원래는 친구 초대·계정 시스템을 만들고 싶었지만, 오늘 안에 끝낼 수 있는 크기로 줄였다.

다듬은 것 (Design Changes)

  • 배경을 연보라 파스텔 그라데이션으로 바꿈
  • 궁합 점수를 동그란 게이지로 표시
  • 카드에 둥근 모서리와 부드러운 그림자 추가
  • 버튼에 마우스를 올리면 살짝 커지게
  • 결과가 아래에서 떠오르며 나타나게

Before → After

전후
전체 느낌흰 배경에 글자만 있는 화면연보라 파스텔 배경에 카드가 떠 있는 느낌
점수숫자만 덩그러니동그란 게이지 안에 큰 숫자
결과 화면그냥 아래에 붙어서 나옴아래에서 살짝 떠오르며 등장

🐞 막혔던 것

문제
디자인을 바꾸고 나니 궁합 보기 버튼이 눌리지 않았다.
원인
새로 넣은 배경 레이어가 버튼 위를 덮고 있었다.
해결
배경을 맨 뒤로 보내 버튼이 위에 오도록 순서를 바꿨다.
배운 것 — 디자인을 바꾸면 기능이 그대로 되는지 꼭 다시 눌러본다.

직접 확인한 것 (Test)

  • 새로 넣은 링크 복사가 작동한다
  • 원래 되던 궁합 계산이 그대로 작동한다
  • 버튼·입력·결과 화면 모두 정상
  • 휴대폰 크기에서도 글자가 읽힌다

친구 파티 궁합 분석기

밝은 파스텔 + 카드 게임 UI, 큰 버튼과 또렷한 결과

사용자 흐름 (User Flow)

홈 · 궁합 보기→ 친구 A/B 입력→ 분석→ 결과 카드 등장→ 다시하기

화면별 명세

Home
목적: 한눈에 뭘 하는지 알리기
주요 콘텐츠: 큰 제목 + 캐릭터 일러스트 + 시작 버튼
주 행동: 궁합 보기 버튼 · 보조: 만든 사람 소개
결과: 입력 화면으로 이동
Input
목적: 부담 없이 빠르게 입력
주요 콘텐츠: 이름칸 + 특징 태그 선택/입력
주 행동: 분석하기 버튼 · 보조: 예시 넣기
결과: 로딩 후 결과로 이동
Result
목적: 결과를 재미있게 보여주기
주요 콘텐츠: 캐릭터 카드 2장 + 큰 궁합 점수 + 한줄평
주 행동: 다시하기 · 보조: 이미지 저장
결과: 새 궁합 분석 시작

UI 요소

Button
둥근 모서리, 큰 글씨, 눌리는 애니메이션
Input
placeholder 예시가 있는 큰 입력칸
Card
그림자 있는 흰 카드, 캐릭터 이모지
Navigation
뒤로가기 화살표
Result
0-100 점수 게이지 바

비주얼 & 모바일

Visual

  • Mood: 밝고 귀엽고 활기찬
  • Colors: 파스텔 핑크·보라·민트
  • Type: 둥근 고딕, 큰 제목
  • Shape: 둥근 모서리 카드
  • Motion: 카드가 통통 튀며 등장

Mobile

  • 세로 한 줄 배치
  • 버튼 최소 높이 48px
  • 점수 게이지 화면 폭에 맞춤

3개 시안 공통 — 맥북에서 요소를 건드는 인터랙션

  • 하단 Dock 확대: 커서에 가까운 아이콘이 종형 곡선으로 부드럽게 커지고, 클릭하면 통통 튐
  • 유리 표면 빛 반사: 카드 위에서 커서를 따라 스페큘러 하이라이트가 이동
  • 스프링 눌림감: 버튼·카드를 누르면 살짝 눌렸다 튀어오르는 물리 반응
  • 신호등 창 컨트롤: hover 시 ×/−/+ 글리프 등장 (시안 1)
  • iOS 세그먼티드 네비: 탭 전환 시 알약 인디케이터가 미끄러져 이동
  • 패럴랙스 틸트: 패널이 커서를 향해 3D로 기울어짐 (시안 3)
